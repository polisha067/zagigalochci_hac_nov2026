# Транспортная стратегия 2030/2035: контекст проекта

Изучен предоставленный PDF: **285 страниц**, распоряжение от **27.11.2021 № 3363-р**, «Транспортная стратегия Российской Федерации до 2030 года с прогнозом на период до 2035 года». Файл идентифицирован по содержимому и SHA-256 в `context.json`, а не по случайному имени загрузки. Актуальная редакция на текущую дату и выполнение планов не проверялись.

Текстовый поиск выполнен по документу; ключевые страницы целиком прочитаны и отрисованы для сверки: 1, 130, 148, 156, 258, 259. Номера здесь — **страницы PDF с единицы**, они отличаются от напечатанной нумерации.

## Что учитываем в архитектуре

| Страница PDF | Содержание | Применение в проекте |
|---|---|---|
| 130 | Мультимодальные логистические центры, расписания, консолидация, складирование и перегрузка | Маршрут состоит из подтверждённых услуг и операций в хабах. Накопление и ожидание включены в срок/стоимость. |
| 148 | Цифровое планирование и качество логистики | Показываем стоимость и сквозной срок на одинаковом объёме; не превращаем целевые улучшения в готовые коэффициенты перевозки. |
| 156 | Обмен данными о грузах и транспортных услугах, сервисные модели | Форма и ИИ обращаются к одному расчётному API и используют одинаковые числа и источники. Интеграция с государственными платформами не заявляется. |
| 258–259 | Базовый и консервативный сценарии перевозок | Сохранены отдельно как макросценарный контекст с единицами и происхождением. Это не ряд конкретного направления. |

Свободный ввод названия груза и гибкая частота — **требования команды/Полины**, а не утверждение, что стратегия предписывает именно такой интерфейс.

## Что извлечено

В `context.json` — **32 значения** двух таблиц приложения № 4: два сценария × четыре ряда × четыре года (2019, 2024, 2030, 2035). Ряды: общий объём без трубопроводного транспорта, авто, железнодорожный, внутренний водный. Единица — млн тонн.

2019 помечен как историческая база внутри стратегии. 2024, 2030 и 2035 — **сценарные значения документа 2021 года**, в том числе 2024 не выдаётся за наблюдавшийся факт. Остальные таблицы PDF не объявляются загруженными. Общая строка не восстанавливается принудительно сложением выбранных видов транспорта.

Эти числа не используются автоматически как рост спроса по любому маршруту, скидка на тариф, подтверждение построенного объекта или свободная пропускная способность. Для отдельного сценария их можно обсуждать с командой, явно обозначив географию, год документа и переносимость допущений. Статистический прогноз пилотного потока требует собственной истории и проверки качества.

## Импорт

```bash
python -m backend.import_sources context backend/data_sources/strategy/context.json
```

Снимок хранится в `reference_context` базы наблюдений. Оригинальный PDF локально сохранён в `backend/data/context/transport-strategy-2021.pdf` (не в Git). Пользователь сервиса не должен выбирать таблицы стратегии: на основном экране остаются параметры перевозки, результат и относящиеся к нему источники/допущения.
