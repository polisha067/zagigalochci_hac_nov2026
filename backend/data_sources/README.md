# Данные проекта: что используется и насколько подтверждено

Снимки JSON в этой папке — исходные версии для запуска и воспроизводимости.
Их нельзя удалять только из-за большого числа строк: сервер использует их без
скачивания сайтов и без локальных PDF команды.

| Набор | Роль в текущем сервисе | Границы достоверности |
|---|---|---|
| `russia/connectivity.json` | Все пригодные направленные наблюдения из набора 180 городов; основа индекса общей сети | Расстояния/время поездок, не грузовые ставки или свободная мощность |
| `russia/fesco-voyages.json` | Даты морских рейсов и терминалы из проверенных пользовательских PDF | Время суток, фрахт и рабочие параметры сценарные; ограничения записаны в снимке |
| `chukotavia/dataset.json` | Опубликованные авиационные тарифы и плановые рейсы | Не подтверждены свободный тоннаж, приём конкретного груза и полная стоимость |
| `river/network.json` | Красноярск ↔ Дудинка: компонентные ставки и контейнерные операции | Расписание, навигационный сезон и мощности сценарные |
| `pipeline/tariffs.json` | Маршрутные ставки нефти, отдельные операции и справочные длины | Неполная цена; длина магистрали не заменяет тарифное расстояние |
| `rosmorport/references.json` | Справочные сведения 54 портов | Не подтверждают каждый терминал, грузовой допуск и свободную мощность |
| `asop/observations.json` | Проверенные подписи диаграмм: 620 агрегированных наблюдений | Контекст и статистика, не тариф или история конкретного потока |
| `strategy/context.json` | Макросценарные показатели стратегии | Не действующие маршруты, цены или прогноз конкретных поставок |

Текущая проверенная сеть, API и численные сценарные параметры описаны в
[RUSSIA_NETWORK.md](../RUSSIA_NETWORK.md). Источник `russia-freight-assumptions-v1`
в ответе API явно содержит условные тарифы, время, ёмкости и обработку.

## Проверка происхождения

- [AUDIT.md](AUDIT.md), `registry.json` — аудит 31 позиции первоначальной подборки.
  Статус «страница просмотрена» не означает, что набор скачан и подключён.
- `import_report.json` — сохранённый отчёт импорта наблюдений; это не текущий
  счётчик маршрутов общего графа. Текущее покрытие возвращает `/network/russia/options`.
- `document_review.json` в папках перевозчиков и трубопровода — сведения о сверке
  первичных документов, SHA256 и ограничениях. Это не ещё один тарифный каталог.
- Подробности: [АСОП](asop/README.md), [ЧукотАВИА](chukotavia/README.md),
  [река](river/README.md), [Росморпорт](rosmorport/README.md), [стратегия](strategy/README.md).

## Производные файлы

CSV АСОП не хранятся тремя дополнительными копиями тех же наблюдений.
Восстановить общую таблицу, годовые и квартальные строки:

```bash
python -m backend.export_examples --kind asop
```

Результат: `backend/data/generated/asop/observations.csv`, `annual.csv`, `quarterly.csv`.
Формат и метки качества сохранены; JSON остаётся единственным основным снимком АСОП.
Производные выгрузки и локальные базы в Git не добавляются.

## Обновление

Скрипты `build_snapshot.py`/`build_scenario.py` — инструменты подготовки данных;
они не запускаются на каждом пользовательском запросе. Новые ставки и расписания
требуют проверки документа, единиц, дат и включённых компонентов перед пересборкой.
Не все снимки восстанавливаются с нуля автоматически: часть значений сверялась вручную.
Обновление существующих генераторов не заменяет такую сверку.
