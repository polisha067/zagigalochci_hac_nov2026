# Присланные PDF АСОП: результат обработки

Проверка 8 ноября 2026 года. Обработаны **27 PDF, 27 страниц, 52 столбчатые диаграммы, 620 числовых наблюдений**. Все страницы отрисованы и просмотрены. Подписи сверены визуально; локальное распознавание текста использовалось как вспомогательное средство. Значения не оценивались по высоте столбцов. Проценты круговых диаграмм не импортировались.

## Годы и смысл показателей

- Выпуски за полные **2017–2024 годы**, включая сравнительные значения предыдущего года. Поэтому есть наблюдения за **2016–2024**, но 2016 представлен только как сравнительная база выпуска 2017.
- Отдельный выпуск **I квартала 2026** с сопоставлением с **I кварталом 2025**. Это не годовые объёмы 2025/2026; автоматическое умножение на четыре не применяется.
- **PDF за полный 2025 год среди этих вложений нет.** Предыдущие скриншоты с годовыми 2024–2025 не заменены файлами с похожими именами: внутри `vidy_transporta_1.pdf`, `basseyny_i_napravleniya_1.pdf`, `osnovnaya_nomenklatura.pdf` указаны 2023–2024.
- `vidy_transporta_1.pdf` и `vidy_transporta26.pdf` показывают только **отправление из портов**. Подвоза **в порты** за год 2024 и I квартал 2025/2026 в этих двух файлах нет. Для прежних выпусков обычно есть обе диаграммы.
- «Грузооборот» в этих графиках выражен в **млн т**, то есть это масса портовой перевалки. Это не т·км. Бассейны, направления, номенклатура и подвоз/вывоз — разные срезы, их нельзя суммировать как независимые поставки.

## Качество и расхождения

Сохранены **43 записей о расхождениях**: 41 групп межпубликационных расхождений и 2 несовпадения итогов внутри страницы. Метки качества есть у **152 строк**; у остальных 468 таких меток нет. Отсутствие метки не означает доказанную сопоставимость всех лет.

Примеры, сверенные с изображениями:

- Балтийский бассейн за 2023: **248,6 млн т** в `12_2023_basseyny_i_napravleniya.pdf` и **271,3 млн т** как сравнительное значение в `basseyny_i_napravleniya_1.pdf`. Причина различия по самим PDF не установлена. Обе записи сохранены, автоматического выбора «последней правильной» нет.
- Нефтепродукты за 2023: **121,5 млн т** в `12_2023_nomenklatura.pdf` и **141,1 млн т** в сравнении файла `osnovnaya_nomenklatura.pdf`. Скрыто исправлять такое расхождение нельзя.
- В `basseyny_i_napravleniya_v_2017_g.pdf` сумма пяти бассейнов не совпадает с суммой четырёх направлений ни для 2016, ни для 2017. Например, 2017: **580,4 против 786,5 млн т**. Значения переписаны как в источнике; строки отмечены, нужна проверка оригинальной публикации/методики.
- В транспортном PDF `pribytie_otpravlenie.pdf` за 2016–2017 единица на странице не напечатана. Эти **20 записей** сохранены с `source_unit=unknown`, `value_tonnes=null`. Миллионы тонн не подставлены по сходству с соседними выпусками.
- В сухогрузном графике I квартала 2026 у пяти позиций нет названий под осью. Эти **10 значений** сохранены как `unlabeled_02/04/06/08/10`; названия руды, зерна и других грузов не угаданы по положению столбца.
- В квартальном PDF по бассейнам круговой график направлений подписан «Доля в 2025 г.», тогда как столбчатая легенда содержит I квартал 2025 и I квартал 2026. Проценты не импортированы; числовые подписи столбцов сохранены с их легендой.
- Классификация грузов меняется: «уголь» и «уголь, кокс», «металлы» и «чёрные/цветные металлы» сохранены раздельно. Состав «прочих» зависит от выпуска, поэтому эта группа тоже отмечена. Отсутствующая категория не заменяется нулём.

Числа в миллионах тонн переведены в тонны умножением на 1 000 000, но точность осталась исходной. Подпись 0,1 млн т не означает точность до одной тонны. Сохраняются десятичные знаки и половина шага округления. При поиске межпубликационных расхождений учитывается сумма этих полушагов; простое различие записи `28.1` и `28.15` само по себе не объявляется конфликтом.

## Что сохранено в проекте

- `observations.json` — основной снимок: метаданные 27 PDF, 620 наблюдений, определения показателей и все 43 записи о расхождениях.
- CSV-варианты `observations.csv`, `annual.csv`, `quarterly.csv` восстанавливаются из JSON командой `python -m backend.export_examples --kind asop` в `backend/data/generated/asop/`. CSV UTF-8 BOM, разделитель `;`, исходные десятичные строки с точкой. Метки качества сохранены. Производные копии исключены из Git.
- У каждой записи: исходный файл и его SHA-256, страница, показатель, категория, период, роль текущего/сравнительного года, единица, значение и оговорки. Дата публикации не установлена; дата проверки не подменяет её.
- Оригиналы PDF локально скопированы в `backend/data/asop/raw/<source_file_id>.pdf`; каталог исключён из Git вместе с остальными локальными данными. В Git попадут обработанный снимок и документация, если команда их закоммитит.
- В `backend/data/network-observations.sqlite3` добавлены `asop_files`, `asop_observations`. Два ранее импортированных источника «Точно» сохранены. SQLite пользователей и SMTP-настройки не затрагивались.

Импорт обработанного снимка на другой машине, из корня репозитория:

```bash
python -m backend.import_sources asop backend/data_sources/asop/observations.json
```

PDF-библиотеки и OCR серверу не нужны: он импортирует уже проверенный JSON. Это не универсальный автоматический распознаватель новых диаграмм. При поступлении новых PDF сначала требуется такая же сверка подписей, единиц и легенд.

## API и использование

`GET /network/statistics/asop` требует обычную сессию. Данные читаются из локальной БД наблюдений.

Примеры:

```text
/network/statistics/asop?metric=basin&year=2024
/network/statistics/asop?metric=basin&year=2023&include_flagged=true
/network/statistics/asop?year=2026&period_kind=Q1&include_flagged=true
```

По умолчанию `period_kind=year`, `include_flagged=false`: строки с любыми метками качества исключены. Для просмотра исходных разночтений передать `include_flagged=true`. Параметр `source_file_id` выбирает конкретную публикацию; без него могут прийти несколько публикаций одного года. Их **нельзя складывать**. Ответ содержит `source_files`, фильтры и предупреждение, а не готовый единственный «очищенный» ряд.

Доступные показатели: `port_inbound`, `port_outbound`, `basin`, `direction`, `dry_cargo`, `liquid_cargo`. Объёмы не создают транспортные услуги, тарифы, расписания, стыковки и свободную мощность хабов. Их назначение — статистический контекст и отдельные агрегированные ряды для последующего анализа. Обучение прогноза и замена тестовых тарифов по этим данным не выполнялись.
