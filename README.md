# Попутно

«Попутно» помогает выбрать, как доставить груз дешевле и уложиться в срок. Можно проверить, стоит ли везти груз напрямую машиной или выгоднее собрать несколько партий и отправить их по железной дороге.

## Как это работает

- Нужно задать города отправления и доставки, параметры груза, график отправок и максимальный срок. Сервис сравнивает доступные маршруты по стоимости и времени. Параметры можно ввести в форме или описать в чате с ИИ-ассистентом.
- Для 12 направлений есть отдельный расчёт по прогнозу объёмов. На одном и том же объёме сравниваем три схемы: разовые авторейсы, рейсы по договору и «авто + ж/д + авто». Выбираем самый дешёвый вариант из тех, которые доставляют весь груз в срок.
