# Доработки прогноза — feature/front-dorab

В `feature/forecast_detailed` используется интерфейс `feature/polisha/diz`.
В него перенесены настройки остановок без перегрузки, данные об актуальности
тарифов и сценарии стыковки в Екатеринбурге.

База ветки: `origin/feature/polisha-front-last`, коммит `7bd88b4`.

## Интерфейс

- `Select.tsx` заменяет системные списки в условиях, истории, подробном отчёте и прогнозе объёма. Меню открывается поверх карточек, имеет ограниченную высоту, поддерживает стрелки, Enter, Escape, Home/End и поиск по первым буквам. Размер текста меню не наследуется от крупного значения года.
- `SuggestInput.tsx` оформляет подсказки груза и условий обращения, сохраняя возможность ввести своё значение. Города по-прежнему ищутся через `SettlementPicker` и серверный API.
- Вес и объём используют короткие подписи, одинаковую высоту поля и общую линию ввода.
- `ForecastChart.tsx` рисует диаграммы с нулевой шкалой, единицами, подписями периодов и точными подсказками, доступными с клавиатуры.

## Соответствие расчётам

Фронт не пересчитывает тарифы или индексы. Центральная оценка и интервал берутся из кандидата, рекомендованного сервером. Показывается только полная стоимость допустимого варианта.

Стоимость: `total_cost_rub = sum(cost_items[].amount_rub)`. Разбивка группирует те же начисления по `kind` и показывается при совпадении суммы с итогом с допуском 0,011 рубля. Погрешность допускает только особенности сложения десятичных чисел в JavaScript. Изменение к базе: `(total_cost_rub / forecast_price.base_rub - 1) × 100%`.

Сервер рассчитывает начисления из базы и коэффициентов индексации (`backend/network/delivery_forecast.py`, `forecast_indices.py`); нормализацию базового года также выполняет сервер. Для авиации действуют отдельные серверные правила. График использует итоговый контракт, не воспроизводит эти формулы приблизительно в браузере.

Годовой график использует точки `forecast_price.annual_series` из ответа сервера. Для совместимого сохранённого расчёта без ряда интерфейс запрашивает его через `/network/russia/forecast-series`. Диапазон прогноза берётся из серверных оценок. В карточке, подписях диаграммы, подсказках и разбивке показываются суммы без округления до сотен рублей. Диапазон отражает сценарную оценку.

Объём: точки берутся непосредственно из `GET /network/forecast`, поля `periods[].forecast_tonnes`. Годовой итог равен сумме периодов. Кварталы и годы агрегирует сервер, не браузер. Метод модели: общий линейный тренд и отдельный уровень каждого месяца; отрицательное предсказание ограничено нулём, месяцы округляются до 0,1 т (`backend/a1_forecast.py`). Синтетический характер исходного ряда остаётся обозначен.
