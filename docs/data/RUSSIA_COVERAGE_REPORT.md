Знаменатель для географии после обновления — все 160 356 записей, доступных через API. Снимок ГАР от 10.11.2026 содержит 160 336 уникальных ID населённых пунктов из 89 региональных файлов с записями. 96 файлов архива проверены, 7 не дали собственных записей для отбора. Старые ID сохраняются. Сопоставлены все 321 пункт от 50 000 жителей из переписи и 89 из 89 записей рабочего списка административных центров по кодам ГАР. Список центров используется для сверки географии, а не коммерческой доступности. Срез переписи датирован 01.10.2021, выгрузка и сопоставление выпущены 25.09.2026. [ФНС, ГАР](https://www.nalog.gov.ru/opendata/7707329152-fias/). [«Если быть точным», выгрузка переписи и привязки](https://tochno.st/datasets/allsettlements).

В новый тарифный снимок вошли **2 767 записей из 29 публикаций**, включая 27 прайсов авто, контейнерные цены «Сибирь Контейнер» и справочные цены «Транзита». Четыре повторные строки отброшены. При сопоставлении расширенного и прежнего тарифных наборов 60 строк остались без однозначной пары точек. Они хранятся в источниках и перечислены в отчёте импорта. У отдельных прайсов нет условий НДС или действующего периода. Для них видна ставка в исходном виде с датой наблюдения, без налогового пересчёта и без добавления в сопоставимую смету. Цены «от» и публикации с неизвестным видом основного плеча доступны справочно. [Прайс «Логистик Авто» из Самары](https://samara.logistic-avto.ru/autopark/gruzoperevozki-do-20-tonn/). [Контейнерные ставки](https://www.tk-container.com/price). [Параметры контейнеров](https://www.tk-container.com/tiporazmery-kontejnerov). [Справочные ставки «Транзита»](https://transitllc.ru/tariffs).

В режиме «Только подтверждённые данные» форма и ассистент показывают опубликованную цену за единицу, дату и источник, прогноз по действующей формуле и известную часть сметы при совместимости данных о грузе и оборудовании. Цена относится к указанной услуге и направлению. Полная цена, срок и наличие места остаются неизвестными, когда источник их не подтверждает. Автомобильное расстояние из прайса и расстояние из дорожного графа выводятся с разными подписями. Поиск в форме использует регионы и районы для различения одноимённых пунктов. Для карты загружаются координаты только участвующих точек.

Грузовой путь и навигационное время доступны с настроенным Valhalla. Для двух опубликованных новосибирских терминалов подвоз и довоз проверяются в правильном направлении. Координаты взяты из ссылок для проезда, которые опубликовал оператор. Результат сортируется по времени подъезда. Допуск, цена подвоза и связь с коммерческим предложением перевозчика остаются отдельными проверками. В пробном запросе к публичному Valhalla от представительной точки Новосибирска до терминала К1 найдено 16,997 км и около 32 минут в движении. Публичный сервер использован только для пробы. Собственный граф всей страны в рабочей среде не развёрнут. [Операции и проезд к терминалам «ТрейдТранс»](https://trade-trans.ru/ru/features). [Документация Valhalla](https://valhalla.github.io/valhalla/api/route/api-reference/).

Фактический объём и грузооборот показываются за 2023 и 2024 годы для России в исходных единицах. В обнаруженных источниках нет сопоставимой истории потоков между выбранными пунктами. Синтетический набор прогнозирования объёма остаётся отдельным. [Росстат, «Россия 2025», стр. 78](https://rosstat.gov.ru/storage/mediabank/Rossia_2025.pdf).

## Приёмка и оставшиеся пробелы

Проверены 30 направлений из приёмочного набора и 8 независимых направлений, по одному на федеральный округ. Для всех запросов груз — 10 т муки в мешках, 20 м³, делимая партия, 2030 год. Пара A → B считается отдельно от B → A. В основном наборе 17 из 30 запросов показали опубликованную ставку на одно или несколько плеч, в независимом — 2 из 8. Полная смета и ряд объёмов по паре не подтверждены ни для одного из 38 запросов. На момент пакетной проверки Valhalla не был настроен, поэтому физическая достижимость этих 38 направлений не оценена. Проба на одном реальном подъезде показала, что подключение роутера работает.

Для расчёта цены независимо перемножены опубликованная базовая ставка и индексы из результата. Проверены отдельно авто и ж/д. Значения округлены до копеек, условия НДС приведены из исходных прайсов. Эти проверки подтверждают расчёт на новых входных данных. Для проверки точности прогноза нужны датированные сопоставимые цены той же услуги за несколько периодов. В новых публикациях такая история не найдена.

| Направление и услуга | Опубликованная ставка | 2028 | 2030 |
|---|---:|---:|---:|
| Самара → Альметьевск, автомобиль до 20 т, НДС не указан | 27 018 ₽ | 33 961,45 ₽ | 42 689,32 ₽ |
| Санкт-Петербург → Новосибирск, контейнер 20 футов, с НДС | 40 000 ₽ | 51 790,16 ₽ | 67 055,53 ₽ |

Для расширения физического покрытия нужен собственный грузовой граф или согласованный экземпляр Valhalla. Для полной железнодорожной цены нужны тарифные расстояния, схемы тарификации и применимые условия официальных правил, данные о допуске, календаре и цене работы терминалов. Тарифное руководство пока не применено. Для полноценных авто и ж/д смет также нужны датированные котировки на подвоз и довоз. Для замены синтетического прогноза объёма нужен исторический ряд с двумя концами маршрута, сопоставимыми периодами, видом транспорта и единицей измерения. Региональные тарифные источники ещё не проверены по каждому субъекту, а статистика по субъектам не импортирована. Федеральные таблицы Росстата при прямой загрузке вернули ошибку цепочки сертификатов, поэтому использована подтверждённая открытая публикация с общероссийскими рядами.

## Повторение импорта и проверки

Из корня репозитория. Скрипт ГАР получает только нужные диапазоны архива и прекращает работу, если сервер не поддерживает их. В исходной загрузке эти части занимали около 140 МБ в сжатом виде. Распакованные источники остаются в локальном каталоге backend/data. Хэши исходных таблиц и версия хранятся в компактном снимке. Импортёр тарифов читает сохранённые HTML, для него нужен пакет lxml. Список обработанных URL и SHA-256 исходных страниц находится в coverage_tariffs.json.

```sh
python -m backend.data_sources.russia.fetch_gar_localities backend/data/coverage-input
# Сохранить CSV ZIP из публикации «Если быть точным» как backend/data/coverage-input/tochno.zip.
python -m backend.data_sources.russia.build_coverage_settlements backend/data/coverage-input
# Сохранить страницы из манифеста как road-<поддомен>.html, sibir.html и transit.html.
python -m backend.data_sources.russia.build_coverage_tariffs backend/data/coverage-input --observed-on 2026-11-13
python -m backend.data_sources.russia.audit_coverage backend/data/coverage-audit.json
```

Машиночитаемый отчёт содержит перечень 38 проверенных направлений, разбивку по регионам и округам, источники и несопоставленные тарифные строки. Для испытания с собственным роутером задайте COVERAGE_VALHALLA_URL и COVERAGE_VALHALLA_GRAPH_VERSION. Рекомендуется повторно прогнать отчёт после настройки, чтобы получить знаменатель проверенной физической достижимости и долю найденных путей.
