# Рыночная модель цены авто и ж/д

Срез 13.11.2026. Калибровка, опубликованные грузовые коридоры и терминальные ставки хранятся отдельно. Сценарный прогноз показывает источники по каждому плечу. Режим «Только подтверждённые данные» использует опубликованные ставки.

Подсчёт относится к применимости ценовой модели на существующих расстояниях для базового профиля груза. Он не подтверждает грузовой путь по всем 109 892 парам. Обслуживание большинства новых автопар пока оценивается по дорожному расстоянию из наблюдений о связности. При настроенном Valhalla для отсутствующих прямых тарифов используются расстояния грузового профиля. Сообщение графа об отсутствии пути или необходимости парома запрещает эту оценку. При недоступности графа используется доступное наблюдение, которое в ответе явно помечено. При отсутствии обоих источников расстояния модель не выдаёт цену.

## Источники и проверка

Для авто использованы 2 556 строк региональных прайсов «Логистик Авто» за фуру 20 т с неизвестным НДС. База рассчитывается по медиане ₽/км для группы расстояний. Для ж/д использован один сопоставимый контейнерный прайс «Сибирь Контейнер» с НДС. 28 направлений каждого типоразмера сопоставились с расстояниями ж/д наблюдений проекта. Эти расстояния служат приближением, а не официальным тарифным километражем. Ж/д модель ограничена диапазоном её обучающих данных и направлениями, где FESCO публикует регулярный контейнерный сервис. Цена модели не относится к котировке FESCO. Прайсы ТЛМ и других услуг не смешиваются с обучающими данными. Подходящий опубликованный тариф имеет приоритет.

| Модель | Строки в отложенных парах | Строки с оценкой | Медианная абсолютная процентная ошибка |
| --- | ---: | ---: | ---: |
| Авто, 20 т | 467 | 465 | 23,8% |
| Ж/д, контейнер 20 футов | 6 | 2 | 73,9% |
| Ж/д, контейнер 40 футов | 6 | 2 | 19,9% |

Прямое и обратное направления попадают в одну часть выборки. Проверка измеряет перенос на другие пары в тех же прайсах, без независимого перевозчика или проверки на фактических счетах. Ж/д результат на двух отложенных наблюдениях не подтверждает точность, поэтому все модельные ж/д цены помечаются как предварительные. Предложенные ранее 50 узлов и 160–260 ж/д наблюдений остаются целями дальнейшего расширения.

Базовая цена индексируется действующей формулой. При нескольких единицах транспорта оценивается равномерная раскладка одной делимой партии. Для сценарных ж/д оценок используются действующие в проекте вместимости 18 т и 28 м³ либо 24 т и 58 м³. При отсутствии автообъёма используется 86 м³. Цены в разных налоговых базах показываются по плечам. Если все автоплечи имеют неизвестный НДС, выводится сумма в исходной базе с соответствующей пометкой.

В маршруте с посещениями модель оценивает соседние пары по порядку. Для смены вида транспорта нужен узел с опубликованными операциями перегрузки. Сумма плеч не включает отдельные операции, ожидание и стоимость сквозного заказа. Забор и выгрузка отдельных грузовых позиций и условия «без перегрузки» остаются в основном расчётном модуле. Справочные цены Клещихи показаны по типоразмеру только для опубликованных направлений вывоза. Они не суммируются с ж/д ставкой до проверки фактической станции, формы выдачи и состава услуг.
