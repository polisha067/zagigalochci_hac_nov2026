# Индексы прогноза стоимости перевозки

Публикации перевозчиков, новые базовые ставки и пробелы по каждому виду транспорта перечислены в [каталоге данных для прогноза](PROVIDER_EVIDENCE.md).

Снимок [indices.json](../../../backend/data_sources/delivery_forecast/indices.json) содержит индексы грузовых тарифов по России за 2012–2025 годы. Единица — проценты, декабрь к декабрю предыдущего года. Для каждой записи указаны год, значение, ID публикации и тип записи. Общие метаданные включают реквизиты публикаций, дату сбора, географию и версию.

- 2012–2013 — таблица 6.1. [Цены в России, 2016](https://rosstat.gov.ru/storage/mediabank/cena_2016.pdf#page=117)
- 2014–2016 — таблица 6.1. В публикации есть оговорка о географии в 2015 году. [Цены в России, 2018](https://rosstat.gov.ru/storage/mediabank/Cena-2018.pdf#page=107)
- 2017–2019 — таблица 25.30. [Российский статистический ежегодник, 2020](https://rosstat.gov.ru/storage/mediabank/Ejegodnik_2020.pdf#page=574)
- 2020–2023 — таблица 6.1. [Цены в России, 2024](https://rosstat.gov.ru/storage/mediabank/Cena_2024.pdf)
- 2024–2025 — таблица 10. Значения за 2025 год предварительные в данном выпуске. [Социально-экономическое положение России, 2025](https://rosstat.gov.ru/storage/mediabank/osn-12-2025.pdf#page=153)

База 2026 года использует опубликованные ставки ТЛМ на подходящих авто- и ж/д направлениях. Для остальных направлений используются сценарные ставки сети. Для авто и ж/д используются отдельные ряды индексов. Перегрузка и хранение индексируются отдельно по сводному грузовому индексу как приближению. Он отражает изменение затрат на грузовое транспортное обслуживание, без выделения склада или терминала. В выдаче такие начисления помечены как приближение.

## Проверка на истории

Для авто на один год применяется медиана пяти автоиндексов. Для авто от двух лет и ж/д на любой срок применяется среднее геометрическое пяти отраслевых индексов. Горизонт выбора формулы считается от года базовой ставки. Диапазон строится по квантилям ошибок выбранного метода с учётом разрыва между последним наблюдением и базовой ставкой при наличии хотя бы трёх окон. [Сравнение моделей и проверка после изменения](forecast_hypotheses_.md)

Таблица ниже сохраняет исходное сравнение прежней модели с медианой, фиксированной ценой и последним индексом на окнах без пропуска года. Метрика — средняя абсолютная относительная ошибка накопленного коэффициента. Покрытие прежней модели рассчитано на тех же окнах, из которых получены границы.

Для базовой цены 2026 года прогноз на 2030 год применяет четыре коэффициента за 2027–2030 годы. При калибровке диапазона для этого примера исторические окна пропускают один год после последнего наблюдения. При наличии менее трёх окон результат маркируется как долгосрочный сценарий без калиброванного диапазона.

Расчёт доступен через `POST /network/russia/forecasts` и инструмент `estimate_future_delivery_cost` ассистента. Год без даты использует типовую фазу суточного профиля ж/д и относительное время. Окна опубликованных речных, морских и авиационных рейсов сохраняют исходные границы. Цена и срок зависят от ограничений, объёма и выбранной цепочки.
