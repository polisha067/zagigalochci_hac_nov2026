# Речной сценарий

Файлы набора находятся в [`backend/data_sources/river`](../../../backend/data_sources/river).

Реальные опубликованные компонентные ставки «Трасса-Экспресс» и синтетические параметры
недостающих ресурсов. Формулы, настройки, границы применения и API: [RIVER.md](../../calculations/modes/RIVER.md).

- `network.json`: самостоятельный каталог существующего сетевого ядра.
- `build_scenario.py`: воспроизводимая сборка, без внешних зависимостей и сетевых запросов.
- Исходная страница (не в Git): `backend/data/river/trassa-express-2026.html`.
- Сборка: `python -m backend.data_sources.river.build_scenario`.

Статус цены fact означает факт публикации, не подтверждение рейса.
Весь сценарий не соответствует verified_only. Никаких тарифов других компаний
или параметров из авиационного набора в него не подставляется.
