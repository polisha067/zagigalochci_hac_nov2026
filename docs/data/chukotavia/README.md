# Проверенный снимок ЧукотАВИА

Файлы набора находятся в [`backend/data_sources/chukotavia`](../../../backend/data_sources/chukotavia).

Применение, формулы и API: [AVIATION.md](../../calculations/modes/AVIATION.md).

- `dataset.json` — тарифы, расписания, датированные сегменты, правила и источники.
- `document_review.json` — OCR всех страниц тарифных PDF, сверенных с изображениями;
  справочник, не вход для автоматического назначения дополнительных сборов.
- `fetch.py` — загрузка открытых документов, не вызывается при запуске сервера.
- `build_snapshot.py` — сборка проверенной транскрипции тарифов и HTML-расписаний;
  lxml требуется только в среде подготовки данных.

Загрузка: `python -m backend.data_sources.chukotavia.fetch`.
Сборка: `python -m backend.data_sources.chukotavia.build_snapshot`.
Оригиналы и manifest: `backend/data/chukotavia/` (игнорируются Git).
Транскрипция привязана к SHA-256 PDF: изменение файла требует повторной проверки.
Скачивание новой версии само не заменяет рабочие ставки.

Три прейскуранта и четыре изменения просмотрены целиком. Их услуги не суммируются
автоматически с грузовой ставкой: неизвестны применимость и плательщик каждого сбора.
Ставка за самолёт, полётный час или пассажирский билет не является ставкой за кг груза.

312 строк тарифов перенесены с четырёх страниц каждой версии. Обратные направления
проверены по таблице. Суммы без НДС транскрибированы, суммы с НДС вычислены как ×1.22
и сверены с опубликованными колонками.

Пять условных строк без дат исключены. Для АД51 заявлено 14 рейсов, но перечислено 13
дат: сохранён флаг, строка не участвует в автоматическом расчёте.
Сохранены абзацы месяцев/дней и объединённые ячейки rowspan/colspan.
Сезонные часы сопоставлены с месяцами. «Нунлигран» приведён к «Нунлингран» из тарифа,
«Усть Белая»/«Усть-Белая» и «Мыс Шмидта» нормализованы. Нечёткое сопоставление
произвольных названий не используется.

Статус `fact` означает факт публикации, а не состоявшуюся сделку или бронирование.
