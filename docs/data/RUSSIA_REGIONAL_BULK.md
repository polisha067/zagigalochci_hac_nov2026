# Крупные партии по России

Снимок `backend/data_sources/russia/regional_bulk_market.json` проверен 13 ноября 2026 года. Он содержит 11 направлений авто из Москвы по прайсу «Бюро перевозок» от 1 октября 2026 года и 3 авианаправления из Москвы по октябрьским прайсам СТК. Два города входят в оба набора. Обратные ставки требуют отдельного источника.

Для авто берём максимум фактического веса и расчётного веса по плотности перевозчика с поправкой 1,1 на объём. Используем верхний тарифный диапазон, если платный вес превышает 2 т. В сценарии прибавляем минимальный въезд на склад на каждую расчётную машину (20 т / 90 м³). Для авиа используем тариф генерального груза свыше 1 т и плотность 167 кг/м³. НДС учитывается по соответствующему прайсу. К базе применяется действующий индекс выбранного вида транспорта.

Расчёт включается для разовой перевозки делимого сухого груза в стандартных местах без заданных остановок и предельного срока. Для регионального отправления нужен расчёт автоплеча до Москвы, а передача между перевозчиками оценивается по опубликованному ориентиру экспедирования в пределах МКАД. Довоз, сборы за отдельные накладные, специальные услуги, фактическая укладка, наличие мест и график требуют котировки. Такие варианты помечаются сценарными.
