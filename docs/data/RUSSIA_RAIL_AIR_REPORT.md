# Покрытие ж/д и грузового авиа

Срез источников проверен 13 ноября 2026 года. Расчёт подключён к прогнозу стоимости, гостевой форме и ассистенту. Для сравнения взяты 332 приоритетных населённых пункта выпуска ГАР от 10.11.2026. Среди них 109 892 возможных направленных пар. Маршрут туда и маршрут обратно считаются отдельно.

| Что можно оценить | Все пункты каталога до → после | Пары внутри приоритетного списка до → после |
| --- | ---: | ---: |
| Ж/д, опубликованная ставка на направление | 36 → 71 | 34 → 43 |
| Авиа, один опубликованный тариф на направление, в том числе сквозной тариф с транзитом | 33 → 730 | 33 → 632 |
| Авиа, оценка по одному тарифу или комбинации двух опубликованных тарифов | 33 → 1 372 | 33 → 1 068 |

Для 10 т сухого груза в мешках объёмом 20 м³ в 2030 году доступны 80 одноплечевых ж/д оценок, включая 52 пары из приоритетного списка. Для 55 дополнительных пар есть цены отдельных плеч через грузовой узел. У 21 из них налоговая база позволяет сложить цены. Стоимость перегрузки и переход между станциями уточняются отдельно. Модельная ставка ж/д применяется на подтверждённых грузовых направлениях в пределах калиброванного диапазона.

Авиа измерено на 100 кг сухого груза объёмом 0,25 м³. В 97 населённых пунктах есть хотя бы одна оценка для отправления или назначения. Для 642 пар без единого тарифа можно оценить отдельные отправки со стыковкой в одном аэропорту. Объёмный вес, минимальный платный вес и часть опубликованных сборов учитываются по правилам источника. Общая ставка применяется к одной расчётной отправке с платным весом менее 500 кг. В сценарном режиме делимую партию можно оценить как несколько равных по массе и объёму отправок. Фиксированные сборы начисляются за каждую. Укладка, допустимые габариты отдельных мест и количество рейсов требуют подтверждения. В режиме опубликованных данных для такой партии показывается причина, по которой требуется котировка. Прайсы GENERAL рассчитаны на обычный груз. Для опасного, температурного и иного специального груза нужны соответствующие условия и ставки.

Опубликованные ставки являются базой прогноза, а не бронированием, подтверждённой ценой или расписанием на 2030 год. Синтетические авиарейсы и авиаставки не добавлялись. Новые суммы рассчитаны из опубликованных тарифов. Известные ж/д сервисы могут использовать существующую модель, если для направления выполняются условия калибровки. Фактические ряды объёмов грузоперевозок в этом изменении не расширялись.

## Воспроизведение

Снимки `rail_market_rates.json`, `air_market_rates.json` и `aeroflot_winter_2026.json` лежат в `backend/data_sources/russia`. Ставки сверены с опубликованными таблицами, загрузка снимков при расчёте работает локально. Для проверки каталога и выборки из 24 направлений по восьми округам выполните из корня:

```powershell
python -m backend.data_sources.russia.audit_rail_air
```

В выборке без внешнего дорожного графа хотя бы одна оценка получена на 22 из 24 запросов. По видам транспорта 16 авто, 6 ж/д и 10 авиа. Для Новороссийска → Владивостока каталог содержит грузовой поезд FESCO, но для ж/д цены нужна котировка. Для Биробиджана → Благовещенска сопоставимой цены не нашлось. Выборка целевая и не оценивает вероятность получить цену на произвольной паре по стране.

Проверено совпадение авиационного расчёта Красноярск → Калининград в API гостевой формы и ассистента. Для контрольного маршрута Москва → Екатеринбург → Красноярск с остановкой 2 часа расчёт выдаёт те же схемы на 2030 и 2028 годы с пересчитанными ценами. Пройден тест расчёта последствий задержки в Екатеринбурге.
