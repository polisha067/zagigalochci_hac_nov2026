# Выгрузка Росморпорта: справочник объектов

Файлы набора находятся в [`backend/data_sources/rosmorport`](../../../backend/data_sources/rosmorport).

Вход: предоставленный командой `ports.json`, SHA-256 сохранён в `references.json`. Проверена структура файла, уникальность id, форматы дат, источников, координат и числовых единиц. Сайты по каждой ссылке заново не обходились: происхождение — **user_provided_scrape**, а не независимая проверка каждой карточки на дату расчёта.

Получено:

- **54 порта**: 18 подробных карточек, 36 записей только из списка.
- **18 пар координат**, переведённых из градусов/минут/секунд. Это указанные местоположения портов, не координаты конкретных терминалов или причалов.
- **259 технических характеристик**, из них 181 нормализована при однозначном числовом значении и известной единице. Остальные сохранены с исходным текстом, без догадки.
- Описание навигации, услуг, портовых сборов и ссылки на документы сохранены как справочная информация. Ссылки на сборы сами по себе не превращены в готовые цены всей цепочки.

## Ограничения применения

Файл содержит портовые карточки и суммарные характеристики терминалов. Это не структурированный реестр каждого грузового терминала с допусками и ценами его операций. В частности, наличие пассажирского порта в перечне не означает приём грузов.

ДФЭ/год остаётся ДФЭ/год; тоннаж не выводится из числа контейнеров. Площадь склада не переводится в свободные тонны. Годовая пропускная способность не делится на 365 для получения доступного слота. Максимальная осадка/габариты порта не гарантируют тот же допуск на каждом причале. «Круглогодично» не создаёт рабочие окна и подтверждение рейса на любую дату.

Поэтому **0 оперативных хабов, 0 грузовых услуг, 0 тарифов** автоматически добавлено в расчётную сеть. Каждая запись имеет `operational_hub=false`, `available_capacity=null`, `services=[]` и список того, что нужно подтвердить для расчёта. Справочник хранится отдельно от синтетического каталога; физические порты не соединены с учебными тарифами.

Для продвижения записи в оперативный каталог нужны конкретный терминал, допуск груза/упаковки, рабочие окна и актуальные ограничения, операции обработки с ценой, подтверждённые услуги до/после терминала, доступная мощность и даты действия сведений. После этого портовая справка может поддерживать проверку параметров конкретного объекта, а не заменять её.

## Файлы и импорт

`references.json` содержит нормализованный снимок с исходными значениями и источниками. Оригинальный вход локально сохранён в `backend/data/context/ports-original.json` и исключён из Git.

```bash
python -m backend.import_sources context backend/data_sources/rosmorport/references.json
```

Снимок записывается в `reference_context` отдельной БД `backend/data/network-observations.sqlite3`. Нового экрана статистики для пользователя не добавлялось. Это внутренний справочник команды и основа последующего наполнения сети.
